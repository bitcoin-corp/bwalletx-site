Make strategies. Sell them on the Exchange.

A strategy is a program your agent runs: when to buy, sell or send, inside limits the wallet enforces. You don’t need to code. Tell the b agent what you want and it writes the strategy, tests it against live prices, and packages it for sale. Other people buy it on Exchange › Strategies and load it into their own agent.

The b agent does the work

1 · Describe it

Say it in plain words: “slowly build up $HANDLE without chasing pumps”. b asks what it needs to know: budget, tokens, when to stop.

2 · b writes and tests it

b turns your answers into a strategy (goals plus exact rules) and tests it against live prices first, so you see what it would do before it trades.

3 · b packages it to sell

When you’re happy, publish it from the chat: b helps you fill in the listing spec, locks the program in an encrypted NFT and lists it in Exchange › Strategies at your price: one-off or limited editions. Use it yourself too.

Or buy one

Browse Exchange › Strategies, compare specs, buy, and load it into an agent account. Resell it later like any NFT.

Make your own, step by step

Tell the b agent what you want, for example "slowly build up $HANDLE without chasing pumps". It asks questions and turns your answers into a strategy: plain-language goals plus exact rules. Test it against live prices, then run it live in an agent account and let its results speak for it.

Rules the wallet enforces

Every strategy has fixed limits: which tokens, how much per trade, how much per day, when to stop. The wallet checks them before anything is signed, so an agent can decide when to act but can never go past the limits.

How selling works

Publish & sell in one tap

When you're happy with a strategy, publish it straight from the chat and list it in Exchange › Strategies at your price, one-off or limited editions.

Encrypted

The program is locked inside an encrypted NFT. Anyone can read the public spec; only the owner can open and run it. Resell it like any NFT.

A spec on every listing

Sellers fill in the same spec for every strategy: what it trades, the most it spends, how often it acts, when it stops, and the seller's own risk rating. Easy to compare.
