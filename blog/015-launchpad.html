Launchpad, and checking what we sign

bWalletX 5.1.74 can buy and sell bonding-curve coins. The wallet now checks every trade the server prepares before it signs anything.

What Launchpad is

Launchpad is a filter in Market. It lists BlastPad bonding-curve coins and lets you buy and sell them from inside the wallet.

A bonding curve sets the price from how many coins have been sold. The server builds the transaction for each trade and the wallet signs it.

Launchpad is only in bWalletX. The store builds of bWallet carry none of its code or text.

Confirm before signing

A Buy or Sell tap opens a confirm panel first. It shows the exact token amount, the BSV to the sat, the dollar value, the slippage floor and a line saying trades are final. Nothing is signed until you press Confirm.

Buys have a maximum size. You can only sell once your holdings have loaded.

The wallet checks the server

A confirm panel only shows what the server tells it. So in 5.1.74 the wallet works out the trade itself and compares.

It reads the pool's state from the transaction data the server sends, runs its own copy of the curve, and rebuilds every output. Then it checks:

  • the token output: right token, right amount, going to you;
  • the BSV going into the pool;
  • 0.70% to the house address and 0.30% to the route;
  • the indexing fee, capped;
  • that there are no other outputs;
  • that the server's quote equals ours;
  • that the BSV leaving your wallet is no more than the amount, the indexing fee and 2 sats.

When you sell, the proceeds go to your own account address as a plain output, and that is checked before signing too.

If anything doesn't match, the wallet refuses the plan and releases the pool. We wrote tests for the bad cases: extra outputs, inflated outputs, the wrong token, the wrong amount, the wrong recipient, a short payout and a quote that doesn't match.

The point is simple. A server we run could be wrong or could be broken into. The wallet shouldn't take its word for it.

Indexing a token you hold

A token only shows up properly once the 1Sat indexer is funded to track it. If the indexer reports a token as inactive or out of funds, the token page now shows an Index $X button to anyone who holds it.

If you hold a token but didn't create it, you pay only the indexing cost. No fee to us.

When you mint your own handle's token and open its chat room, we add $1 on top. That is the only time we charge it. The button says the exact sats and whether the fee is included, and the confirm sheet lists each line and the network fee.
