The b agent: paid, or your own key

An assistant inside the wallet. It started free, became paid-only within a day, and now asks for consent before it sends anything.

The first version

On 1 October the b in the centre of the top bar opened the b agent: a chat page built on the chat server's compose feature. It was free to use. Free AI costs us money with no limit, so it did not last.

Paid only

On 2 October we removed the free path. There are now two ways to use the agent:

  • Your own key. You add an API key for Anthropic, OpenAI or OpenRouter. It stays in secure storage on your device, and requests go straight from your phone to that provider. We don't see them.
  • Pay per message in BSV. The wallet asks for a quote, pays and gets the answer, with a daily limit. The price is set in US dollars and converted to sats at quote time. These messages go through our server to Anthropic.

We also cut the history sent with each message from 20 turns to 8. That lowers cost and sends less of your conversation.

Consent

For the stores, and because it is right, the agent now shows a consent sheet before the first message to each provider. It says what is sent (your message and the last 8 turns) and what isn't. You can revoke consent in Settings. The agent also refuses input that looks like a recovery phrase or a private key.

On 5 October we added a banner on the agent page to add your own key, since that is the more private option.

What it can do

The agent has a usage guide for the wallet as its system prompt, so it can explain features. In agent accounts it can act, buying and sending, but only through the strategy rules the wallet enforces (post 010). Quick-start buttons cover the common cases: create a strategy, trade with a strategy, buy or sell one.

What's not done

  • The store build allows only your own key; pay-per-message is a private-build feature.
  • The agent can be wrong. Any action it takes in an agent account is limited by the strategy gate, not by its judgement.
  • There is no long-term memory, by design, and no way yet to export a conversation.
