Four names in a week

Yours Wallet Mobile, bCorp Wallet, bWallet, then bWalletX. Why the name kept changing, and why there are now two apps.

Yours Wallet Mobile

The first builds were called Yours Wallet Mobile, with an "Experimental" tag and a switch for the brand. That made sense while the port was a gift to the Yours team. It stopped making sense once we started adding our own features, because users could reasonably think the Yours authors stood behind them.

bCorp Wallet, then bWallet

On 30 September the app ID moved to a Bitcoin Corporation one and the store build became "bCorp Wallet". The next day it became bWallet. At build time we also recoloured upstream's greens to a BSV gold, and replaced the Yours sprout with our own mark. That rename touched app IDs, the user agent string (bWallet/1), icons and splash screens. App IDs are hard to change once an app is in a store, so doing this early was cheap compared with doing it later.

Two apps: bWallet and bWalletX

By 2 October it was clear that the App Store and Google Play would not accept everything we wanted to build (more on that in post 007). So we split into release channels. The store builds stay "bWallet". The private builds, with everything turned on, became bWalletX on 3 October.

The "X" itself went back and forth. First we added a small x to the b in the logo. Then the extension shipped with b+x icons. Then a flag-top b with a Space Grotesk X. On 4 October we removed the X from every logo: bWalletX is a gold b on black, and the store bWallet is a black b on yellow. The X now lives only in the name.

Market or Exchange

The same split shows in the tab names. In bWalletX the trading tab is called Exchange. In the store app it is called Market, and it is browse-only. One setting in the code picks the label, so the two apps share the same screens.

Was it worth it

Probably, but it cost time. Every rename meant new icons, new share images, site copy and checks that old installs still update in place. One example: the private iOS channel kept its earlier bundle ID so existing installs would update to bWalletX instead of appearing as a second app. If we did it again, we would decide the store/private split before choosing any name.

What's not done

  • Some older share images and APK file names still use earlier names.
  • The store bWallet has not been approved by Apple or Google as far as our history records.
