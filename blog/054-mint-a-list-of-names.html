Mint a list of names

bMint on bWalletX Desktop now mints OpNS names. Drop in a list, see which names are free, approve the whole batch once, and each name is mined straight into your own wallet.

What an OpNS name is

An OpNS name is a short name, like b0ase, written on the BSV blockchain as a 1Sat item. Whoever holds it owns it, in their own wallet, like any other thing you own there. Anyone can claim a free name, and the first to claim it gets it.

Drop in a list

Open bMint → OpNS on bWalletX Desktop. Drop in a .txt file with one name per line, or paste the names in. Each name is checked live and marked free, taken or yours.

See the bill first

Before anything is paid you get an itemised invoice: the network fee for each name in sats and roughly in dollars, the total, how long mining should take, and your balance. Then one approval covers the whole batch. No popup per name.

Mined into your own wallet

Each name is mined straight into your wallet, one after another, with a progress bar and a link to each transaction. You can pause and pick up again later. Names that start the same way reuse what was just minted, so a list of related names goes faster.

A real batch

We minted 40 names in one go, including b0ase, bchatx, bwalletx, bmoviesx, vexvoid and npg, for about 0.002 BSV in network fees.

Network fees go to the miners and can’t be refunded, even if a name turns out to be taken by someone who got there first.
