Agent accounts, strategies, CLI and MCP

Separate wallet accounts for agents, spending rules the wallet enforces, a market for strategies, and a command-line tool that keeps keys on the phone.

Agent accounts

On 4 October we added a switch when you add an account: Agent account. An agent account is a separate wallet that you fund from your main one. Settings has Stop all, a stop per account, a daily cap, Sweep back for tokens, NFTs and BSV, and an activity log. The idea is that an agent can never spend more than you put in its account.

Strategies

A strategy is a file that says what an agent may do: which tokens, how much, how often, within what limits. The wallet enforces the limits, not the agent. You load a strategy into an agent account, and the b agent can then buy and send there, through that gate.

We first called the dry-run mode "paper mode", with paper fills. On 5 October the site wording changed to "test on live prices", because "paper" and "pretend money" undersold what it does: it uses real market prices without spending.

Selling strategies

Strategies can be sold on Exchange › Strategies as encrypted NFTs. A buyer pays the author plus a 1% fee, gets their own copy minted, unlocks it through our key service and loads it. Since the key service releases the content, buyers depend on it staying up.

Running agents on a computer

There are two ways to run an agent account from a laptop or server with the bwalletx CLI, which is published on npm, along with an MCP server for AI tools:

  • Pairing. Scan a QR code with the phone. The pairing is bound to one agent account, with scopes and an expiry of at most 30 days. Requests run on the phone through the agent gate, so keys never leave it.
  • Key export. For a server with no phone, export a passphrase-encrypted key file. This works only for agent accounts, never for your main wallet.

The CLI pages describe v0.1 and then v0.2, which added pairing and live buys.

What's not done

  • Strategies are new. We have no track record of how they behave over weeks.
  • The strategy key service is ours and centralised; if it is down, bought strategies can't be unlocked.
  • Spec items such as per-agent rate limits and scoped agent tokens are partly built; check the spec page for what is live.
  • Nothing here is financial advice, and agents can lose money within their limits.
