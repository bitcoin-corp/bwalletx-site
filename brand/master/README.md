# Master logos

The one place for the b, bWalletX, bChatX and bMintX logos. Served at
`https://bwalletx.com/brand/master/`. If you need a logo, take it from here. Don't draw one,
trace one or export one from a screenshot.

Every file comes from `build.py` (one geometry, four colour ramps). To change anything, edit
`build.py`, run `python3 brand/master/build.py`, check the 4096px render, and commit the
script and its output together. Needs `rsvg-convert` and `magick`.

## The mark

The b, approved 23 Oct 2026 (brand/bwalletx-mark.svg), on a 120-unit grid:

| Part | Construction |
|------|--------------|
| Stem | x 27 to 45 (18 wide). Top cut at 45°, from (27,30) to (45,12) |
| Bowl | circle at (60,72), r 33 |
| Counter | circle at (60,72), r 15, so the bowl is 18 thick, the same as the stem |
| Join | the stem's left edge (x 27) is the bowl's leftmost point (60 − 33), so the edge runs straight into the arc with no step. The stem's right edge (x 45) touches the counter (60 − 15) |

It is drawn as one path with an even-odd counter: no masks and no overlapping shapes.
In app tiles the letter is scaled to 74% around (56,64), which centres it optically. Avatars
use 68%, maskable and adaptive icons 60% (inside Android's safe circle), and favicons 86%.

## Colours

| Brand | Top | Flat / middle | Bottom |
|-------|-----|---------------|--------|
| b, bWalletX (gold) | `#FFE58A` | `#FFD24D` | `#C98F00` |
| bChatX (silver) | `#DEE1E7` | `#C9CED8` | `#898C93` |
| bMintX (green) | `#76E4C0` | `#22D39A` | `#178F69` |
| Dark ground | `#000000` | | |
| Light ground | `#F4F4F2` | | |
| Ink on light | `#0A0A0A` | | |

The gradient runs top to bottom over the whole letter (y 12 to 105, userSpaceOnUse), so the
stem and bowl share one ramp. A per-shape gradient would show a seam at the join.

On pages the logo is always the gold b, and only the X in the name takes the service colour.
The silver and green letters are only for icons: favicon, app icon, avatar, X app.

## Files (per brand: `b/`, `bwalletx/`, `bchatx/`, `bmintx/`)

| File | Use |
|------|-----|
| `*-mark.svg` | the letter in its gradient, for dark grounds. Page headers, extension toolbar |
| `*-mark-flat.svg` | the letter in one colour (the middle stop). Print, embroidery, single-colour use |
| `*-mark-white.svg` / `*-mark-black.svg` | one-colour letter for photos and light grounds |
| `*-icon.svg` | black rounded tile (corner radius 22%). Web app icon, docs, store tiles |
| `*-icon-light.svg` | light tile with a black b, for light-only layouts |
| `*-icon-square.svg` | full-bleed black square. iOS (it rounds the corners), X app, apple-touch |
| `*-avatar.svg` | black circle. Profile pictures |
| `*-maskable.svg`, `*-adaptive-foreground.svg` | Android: PWA maskable icon and adaptive icon layer |
| `*-favicon.svg`, `*-favicon.ico` | browser tab (16/32/48) |
| `*-x-app-400.png` | the 400×400 to upload to the X developer app and the X profile |
| `png/*-{icon,square,mark,avatar}-{1024,512,400,256,180,128,48,32,16}.png` | the same at fixed sizes |
| `png/*-maskable-{192,512}.png`, `png/*-adaptive-{foreground,background}-432.png` | Android |
| `ios/AppIcon.appiconset/` | iOS app icon set: 1024 single size plus legacy sizes, opaque |

The Chrome extension icon is the gold b alone with no black square (`bwalletx-mark-*.png`).

## Rules

- **Clear space:** keep at least the stem width (18 units, about a quarter of the letter's
  width) clear on every side.
- **Minimum size:** the bare letter 16px tall on screen, 6mm in print. Under 24px use the
  favicon tile, which fills more of the square.
- **Hero size:** about 120px, always next to the name or content. Never show the logo huge
  on its own.
- **Gold on light:** don't. Flat gold on white is about 1.5:1 and the b fades out. On light
  grounds use `*-mark-black.svg` or `*-icon-light.svg`.

## Don'ts

- Don't redraw, retrace or "tidy" the b. Change `build.py` with the owner's OK.
- Don't stretch, rotate, outline, add a shadow or glow, or put an X inside the logo (the X
  goes in the name: bWallet**X**).
- Don't change the gradient direction, or give the stem and bowl separate gradients.
- Don't move the stem foot below y 72. A stem that ends at 76 leaves a small step where it
  meets the bowl (the rough copies on bChatX and bMintX did this).
- Don't put a family colour (silver, green) on a page logo. Those are icon-only.
- Don't screenshot an icon to make a new one. Take the PNG at the size you need.
