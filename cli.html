bWalletX CLI

Your wallet and your agents from the command line, on your laptop or a server.

npm i -g bwalletx→ bwalletx login→ bwalletx agent run

Get started

npm i -g bwalletx                    # Node 20+
bwalletx login --account phone       # shows a QR: scan it in bWalletX from your agent account

In bWalletX (5.1.40 or later), open your agent account, then Settings › Paired websites › Scan to connect. Check both screens show the same 4-digit code, choose what the CLI may do and for how long (1, 7 or 30 days), and tap Pair. Your keys never leave the phone.

For a server with no phone around, export a key file instead: Agents › your agent account › Run on a computer › Export for CLI, then bwalletx key import ./trader.key.json.

Commands

bwalletx accounts                    # paired and imported agent accounts
bwalletx balance --account trader    # BSV and tokens, in dollars
bwalletx price <tokenId>
bwalletx send 1 name@bwalletx.com --account trader
bwalletx buy <tokenId> --max-usd 2 --account phone      # cheapest listing, +1% fee, never over the cap
bwalletx strategy load ./slow-accumulator.json --account trader
bwalletx agent run trader            # run its strategy unattended
bwalletx log --account trader
bwalletx stop                        # kill switch: refuse every spend

What works today (v0.2)

Live

Balances, prices, the activity log, sending BSV to an address or paymail, and buying BSV-21 tokens from the Exchange. Strategies run by agent run trade for real once you load them live.

Paired or key file

Paired (bwalletx login): the phone checks and signs every request, so bWalletX must be open on that agent account. Key file: runs unattended on a server.

Coming

Selling, listing and minting from the CLI.

Your keys stay safe

Agent accounts only

Only agent accounts can be exported, never your main wallet. The key file is encrypted with a passphrase you choose and stays encrypted on disk.

Limits

The agent account's balance is the budget. Every spend is checked first: the kill switch, the daily cap, at most 30 spends an hour, then the strategy's rules. Every action is logged.
