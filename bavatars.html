Every name gets a bAvatar.

A bAvatar is a picture drawn from your Bitcoin name. The same name always gets the same picture, in any app that looks it up, so $you@bwalletx.com looks like you before you upload anything.

Pick your style

Tap a style to make it yours. Each one is shown at full size, then at 40px and 24px, the sizes it appears at in chat lists and replies.

Your bAvatar

Choosing a style is just a preview for now. It's coming to bWalletX: you'll pick it in Settings, and everyone who sees your name will see it.

The QR coin

Your bAvatar as a real QR code in gold dots, with the b mark in the middle. It uses the highest error-correction level, so up to about 30% of the code can be covered by the mark and it still scans. Point a phone camera at it.

It opens

Bloom × Deco × Kintsugi

One avatar that mixes three favourites, then two ways to make it scannable. The art QR works in any phone camera. The code ring leaves the art untouched and stores the name in a gold bezel for the bWalletX scanner.

How it works

Same name, same picture

Every style is drawn from the name itself. Nothing is stored, so any app can draw it, and it only changes if the name does.

Upload still wins

Your own photo always comes first. The bAvatar is the default and the fallback, never forced.

Open to other BSV apps

Planned: a public image link for every name and a small MIT package, so any BSV app can show bAvatars.
