Verify a lock.

Paste the transaction id of a lock or lock receipt. This page reads it from the chain (WhatsOnChain) and checks every lock output itself. It doesn’t trust the receipt’s picture.

What is checked

  • Each output that is a lock: its unlock height and amount, read from the script the network enforces.
  • If the transaction has a bWalletX receipt: that every payout it lists matches a real lock output, to the same key, with the same height and amount, and that the totals add up.
  • Whether each lock has been spent (claimed), from WhatsOnChain. Status: Locked, Partly claimed or Fully claimed.

Heights are block numbers; dates are about 144 blocks a day. About Lock BSV.
