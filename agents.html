Agent accounts: every AI gets its own bBot

An agent account is a separate wallet account that an AI runs for you, with its own keys and its own budget. It trades, sends and reports inside the limits you set, and you can stop it or sweep everything back any time.

The bBot is the agent's face

Make an account an agent account and it gets a bBot, a little helper robot, in its own colour. It shows on the wallet card when that account is selected and is the account's avatar everywhere: the account menu, Settings and chat. One look tells you which agent you're in.

What an agent account can do

Spend only its budget

Its balance is all it can ever spend. Fund it from any of your accounts in one tap; your other accounts are never touched.

Follow a strategy

Agree the rules in plain words, or load a strategy, and it trades by those rules and nothing else. Strategies →

Show its work

An activity log lists every action, with links to the transactions. Add labels and an optional daily spending cap in dollars.

Stop on your word

Stop one agent or Stop all agents. A stopped account refuses every spend until you resume it, and Sweep back moves every token, NFT and all the BSV home.

Many agents

Run one AI per account, or one across several. A Trader on two strategy accounts, a Treasurer that tops them up, a Reporter that only reads: each sees only the accounts you give it.

Pair a computer, or Claude

The bWalletX CLI runs agent accounts on a laptop or a server. Pair it with your phone so the phone signs every request, or export an agent account's key file to run unattended. Every spend is checked first: the kill switch, the daily cap, at most 30 spends an hour, then the strategy's rules.

# install (Node 20+)
npm i -g bwalletx
bwalletx login --account phone   # scan the QR in your agent account
bwalletx agent run trader        # run its strategy
bwalletx stop                    # kill switch
# Claude Code, over MCP
claude mcp add bwalletx -- npx -y bwalletx mcp

Over MCP, Claude, ChatGPT, Cursor or any agent can manage the agent accounts you give it, within the same limits as the app. An AI can only load strategies on paper: going live is a step you take yourself. CLI guide → · MCP guide →

Start in a minute

In bWalletX, open the account menu and tap Add agent account, or go to Settings › Agents. Move in a small budget, give it a strategy, and its bBot appears on the card.
