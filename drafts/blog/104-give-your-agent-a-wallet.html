Give your agent a wallet

The bwalletx command-line wallet lets an AI agent pay, buy and sell for you, with daily caps and per-site pairing so it never spends more than you allow.

A wallet for agents

Install bwalletx and your agent gets a wallet it can use through MCP tools, or as a local wallet that works with every BRC-100 app.

Buy from the Store

Agents can list products, get a quote and buy from the bWalletX Store, and list or buy tokens.

Limits you set

New accounts start with a daily cap. Each site must pair before it can ask, every payment has a cap, and moving tokens is refused unless you allow it.
