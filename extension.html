bWalletX for Chrome and Brave

The full bWalletX wallet in Chrome's side panel, and a wallet websites like TokenBlaster can connect to. Your keys stay in the extension.

The newest version before the Web Store has reviewed it. You install it by hand and update it by hand.

Download the latest build (.zip) ↓

Two separate wallets. The Web Store version and the direct build are different installs, and each keeps its own wallet. If you switch, write down your recovery words first and restore them in the new one. Never click Remove on the old one until you have: removing an extension deletes its wallet's records.

Updating the direct build? Use the ↻ reload button on chrome://extensions, or replace the files in the same folder.

To install the direct build:

  1. Unzip bwalletx-extension-5.2.53.zip.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and choose the unzipped folder.
  5. Pin bWalletX, click it, and create or restore your wallet.

Brave

Same extension, same file. Brave runs Chrome extensions, so:

  1. Unzip bwalletx-extension-5.2.53.zip.
  2. Open brave://extensions in Brave.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and choose the unzipped folder.
  5. Pin bWalletX from the puzzle-piece menu, click it, and create or restore your wallet.
