bWalletX MCP

Let Claude, ChatGPT, Cursor or any AI agent use your bWalletX agent accounts, within the budget and limits you set.

Claude→ ChatGPT · Cursor→ Any MCP agent

What agents can do

Tools (v0.2)

accounts, balance, price, send (BSV, live), buy (live), strategy_show, strategy_load (always on paper), log, stop_all.

Only the accounts you give it

Agents work in agent accounts with their own keys and budget, exported from bWalletX. Your main wallet is never exposed.

Bounded

Every spend passes the same checks as the app: the kill switch, the daily cap, at most 30 spends an hour, then the strategy's rules. An AI can only load strategies on paper; going live is a step you take yourself.

Set up

npm i -g bwalletx
bwalletx login --account phone             # pair with your agent account in bWalletX

Claude Code (paired: no passphrase needed, your phone signs):

claude mcp add bwalletx -- npx -y bwalletx mcp

Or with a key file for an unattended server:

claude mcp add bwalletx -e BWALLETX_PASSPHRASE=your-passphrase -- npx -y bwalletx mcp

Claude Desktop, Cursor and others (MCP config file):

{
  "mcpServers": {
    "bwalletx": {
      "command": "npx",
      "args": ["-y", "bwalletx", "mcp"],
      "env": { "BWALLETX_PASSPHRASE": "your-passphrase" }
    }
  }
}

The passphrase unlocks the agent account's key file on your machine. Use a separate agent account with a small balance for AI agents. Leave the passphrase out and the server stays paper-only: it can read and practise, but never send.
