What agents can do

Since bwalletx 0.2

accounts, balance, price, send (BSV, live), buy (BSV-21, live), strategy_show, strategy_load (always on paper), log, stop_all.

New in bwalletx 0.5 (on npm)

Everything above, plus:

  • list_for_sale, unlist, listings, buy_listing: sell and buy ordinals, OpNS names and BSV-21 tokens on the 1Sat order book. Key-file accounts with BWALLETX_PASSPHRASE; each takes dryRun to build without sending.
  • brc100_balance, brc100_addresses, brc100_fund, brc100_withdraw: the account's own BRC-100 wallet. Key-file accounts with BWALLETX_PASSPHRASE.
  • mint, mint_manifest: mint files as NFTs. Paired accounts only: your phone signs, within the item and dollar limits you chose when pairing.
  • pairing_status, serve_status: read-only checks on pairing and on bwalletx serve (port 3321).

Only the accounts you give it

Agents work in agent accounts with their own keys and budget, never your main wallet. Pair an account with your phone (keys stay on the phone), or export its key file from bWalletX for an unattended server.

Bounded

Every spend passes the same checks as the app: the kill switch, the daily cap, at most 30 spends an hour, then the strategy's rules. Agents can stop everything (stop_all) but never loosen a limit: changing caps, resume, going live with a strategy, importing keys, pairing and starting serve are steps you take yourself at the terminal or on your phone.

Set up

npm i -g bwalletx
bwalletx login --account phone             # pair with your agent account in bWalletX

Claude Code (paired: no passphrase needed, your phone signs):

claude mcp add bwalletx -- npx -y bwalletx mcp

Or with a key file for an unattended server:

bwalletx key import ./trader.key.json
claude mcp add bwalletx -e BWALLETX_PASSPHRASE=your-passphrase -- npx -y bwalletx mcp

Claude Desktop, Cursor and others (MCP config file):

{
  "mcpServers": {
    "bwalletx": {
      "command": "npx",
      "args": ["-y", "bwalletx", "mcp"],
      "env": { "BWALLETX_PASSPHRASE": "your-passphrase" }
    }
  }
}

The passphrase unlocks the agent account's key file on your machine. Use a separate agent account with a small balance for AI agents. Without the passphrase a key-file account stays paper-only: it can read and practise, but never send. Paired accounts don't need it.

Install or update:

npm i -g bwalletx
claude mcp add bwalletx -- bwalletx mcp
