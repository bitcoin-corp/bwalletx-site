Start building on b

bWalletX is our BRC-100 wallet. Around it we build open tools: sign-in and payments for your site, a wallet for your AI agents, on-chain sites with b0-x, and paid work on our own apps through Kintsugi. Here is what works today, and what is coming.

Start in 5 minutes

  1. Get bWalletX Live

    Install the wallet you will build and test with: the web app, the Chrome extension or Android. It is in beta, so test with small amounts.

    Get bWalletX → · Which edition to test with

  2. Add Connect to your site Live

    One script tag and one button give your site a BRC-100 wallet. No API keys and no account with us.

    <script src="https://bwalletx.com/connect.js"></script>
    The quick start → · Sign in with bWalletX, with server code

  3. Check your site with b0-x Live Early access

    Drop your built site folder into b0-x. In your browser, it lists what would go on chain, flags links that would break and estimates the cost. Nothing is uploaded. Publishing on chain is in early access; deploys from Vercel or GitHub are coming.

    Open b0-x New project → · The b0-x docs (draft)

  4. Put your app in the wallet Live

    Send us your app for the Apps screen in bWalletX. A person reviews it, and approved apps ship in the next wallet release. Apps open in the wallet's own browser with BRC-100 sign-in and payments. To try it on your own phone now, open Apps in the wallet and tap + Add app.

    Add your app →

  5. Take a paid Kintsugi task Live

    Kintsugi is how The Bitcoin Corporation contracts the work on bWalletX, bChatX and the b*X apps. Pick a task with a fixed price, sign the contract in bChatX, deliver, and get paid in BSV, in full. There is no Kintsugi fee.

    See the open tasks → · How Kintsugi works

The tools

Each one links to its real docs, package or source. Checked on 6 November 2026.

  • bWalletX

    Live

    Our wallet, built on the open BRC-100 interface. Web, Chrome extension and Android, with CLI and MCP editions for agents.

    Get itDocsSource

  • Connect @bwalletx/connect

    Live

    Version 0.7.0. Sign in with bWalletX, a React provider, Next.js routes, pay and tip helpers, server-side payment checks and a wallet picker. Works with any BRC-100 wallet, including Metanet Desktop on its own tap.

    npmGitHubThe button

  • bwalletx CLI

    Live

    Version 0.5.0. Run bWalletX agent accounts from the terminal: balances, sends, buys and strategies, behind a kill switch, a daily cap and a rate limit.

    npmGitHubCLI page

  • MCP server

    Live

    bwalletx mcp lets Claude, Cursor or any MCP agent use an agent account you give it, within its budget and limits. Agents can stop everything, but never loosen a limit.

    Set it upAgent docs

  • bwalletx serve

    Live

    Turns a key-file agent account into a full BRC-100 wallet on localhost:3321, where BRC-100 sites already look for a desktop wallet. Only the origins you allow get an answer.

    README

  • b0-x New project

    Live

    Checks a built site folder the way the publisher does: what gets inscribed, what is skipped, which links would break, and an estimate of the cost. It stays in your browser.

    Open itPricing

  • b0-x gateway

    Live

    Serves sites published on Bitcoin SV at b0-x.com/s/<name>/: each file an inscription, plus an ORDFS directory. bFriendsX and bVideoX are there now.

    StorageSee one

  • b0-x publisher

    Early access

    pnpm publish-site puts a static site on chain. A dry run lists every file, flags broken links and prints the fee. Broadcasting signs with b0-x's own key, so for now b0-x runs it.

    SourceDocsHow it works

  • b0-x Deploy, Names and CLI

    Coming soon

    Import a project from Vercel or GitHub, build it, publish it, and point an OpNS name at the version you choose. The b0-x commands in the docs are a draft and don't exist yet.

    DeployNames

  • Apps in bWalletX

    Live

    Submit your site for the Apps screen. A person reviews it; approved apps ship in the next wallet release, and open with BRC-100 sign-in and payments.

    Add your appWhat users see

  • bApp shell

    Coming soon

    A /.well-known/bapp.json manifest and the five-slot bar (Wallet, Exchange, b, Feed, Chat) for your app. The web components are in @bwalletx/connect/shell now; bWalletX driving your app from its own dock is coming.

    Shell protocol

  • Kintsugi

    Live

    Paid tasks on bWalletX, bChatX and the b*X apps. Each has a fixed price in a contract you sign before you start. Paid in BSV to your wallet, in full. Larger development work for verified builders is coming.

    Task boardbkintsugix.com

  • bGitX

    Live

    Connect your GitHub repos, give each one a room in bChatX, and let Kintsugi fix and build by pull request. Nothing merges without your OK.

    bgitx.comOn bWalletX

  • BRC standards

    Open standard

    The open BSV standards our tools follow. BRC-100 is the wallet interface: build against it once and every BRC-100 wallet works.

Code you can copy

Copied from the real READMEs and pages, linked under each one.

A Connect button on any page Live

<script src="https://bwalletx.com/connect.js"></script>
<button id="connect">Connect with bWalletX</button>
<script>
  bWalletX.button('#connect', async ({ wallet, identityKey }) => {
    // wallet is a BRC-100 WalletInterface, the same API as window.CWI
    console.log('Connected', identityKey);
  });
</script>
From bwalletx.com/developers

Sign-in with a bundler Live

pnpm add @bwalletx/connect @bsv/sdk
<BwalletXProvider challengeUrl="/api/bwalletx/challenge" verifyUrl="/api/bwalletx/verify"
  logoutUrl="/api/bwalletx/logout" sessionUrl="/api/bwalletx/session">
  <BwalletxSignin size="sm" />   {/* in your header; that's all */}
</BwalletXProvider>
The three routes come from @bwalletx/connect/next. From the @bwalletx/connect README

Give your AI agent a wallet Live

npm i -g bwalletx
bwalletx login --account phone             # pair with your agent account in bWalletX
claude mcp add bwalletx -- npx -y bwalletx mcp
Paired accounts need no passphrase: your phone signs. From bwalletx.com/mcp

Check a site for on-chain publishing Early access

$ pnpm publish-site <dir> [--name x] [--owner <pubkey>] [--source <domain>]
    [--fee 100] [--relative] [--max-tx-mb 9.5] [--broadcast]
A dry run by default: nothing is broadcast. --broadcast is owner only for now. From the b0-x docs
